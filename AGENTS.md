# AGENTS.md
## Objetivo del proyecto
Esta aplicación empezó como un prototipo generado con IA. El
objetivo ahora es convertirla en un proyecto mantenible, claro y
fácil de evolucionar.
## Reglas de trabajo
- Antes de cambiar código, revisa la estructura actual.
- Haz cambios pequeños y fáciles de revisar.
- No borres funcionalidad existente sin explicarlo.
- Mantén componentes pequeños y con responsabilidad clara.
- Mantén los ficheros de código por debajo de unas 500 líneas
cuando sea razonable.
- Separa UI, datos y lógica. Seguir siempre la arquitectura que ya
tiene el proyecto
- Actualiza documentación si cambian comandos, estructura o
comportamiento.
## Definition of Done
Una tarea está terminada cuando:
- la aplicación sigue funcionando,
- el cambio resuelve la tarea definida,
- el código queda más claro o igual de claro que antes,
- se han añadido tests si tiene sentido,
- pasan lint, typecheck, tests y build,
- y queda explicado qué se ha hecho.
